# Subscriptions

A client's subscription carries the master's servers and every bound node's
servers. The node servers are generated by the reconcile (`refreshNodeLinks`)
from the master's replica inbounds and stored in `client.links` as `external`
entries with a `[<node name>] ` remark prefix; serving a subscription never
calls a node.

Policy applied when serving (`service.FilterNodeLinks`, used by
`sub/subService.go` and `sub/jsonService.go`), in memory only:

| Node state | Servers in subscriptions |
|---|---|
| online / degraded / syncing | served |
| offline | served (last good links; clients keep working when the node returns) |
| **Exclude from subscriptions** set | hidden (still stored; re-include restores them instantly) |
| disabled | served (unchanged behaviour); set *Exclude* as well to hide |
| deleted | refused while replicas exist; removing replicas removes their links |

Duplicate external URIs (the same server bound twice) are emitted once. A node
named `a` never hides links of a node named `ab` (the prefix includes the
brackets). Malformed stored links pass through unchanged.

Exclusion is available per node (drawer, Settings tab) and in bulk
(`subExclude` / `subInclude`).
